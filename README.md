# Delhivery Logistics Data Analysis

## Problem

Delivery delays were increasing, but the root causes were unclear.

## Dataset

* 50,000+ shipment records
* Included route, delivery time, carrier, and region data

## Approach

* Cleaned missing and duplicate data using Python
* Performed SQL-based aggregations to identify delay patterns
* Analyzed region-wise and carrier-wise performance

## Key Insights

* Peak load periods caused the highest delays
* Certain routes consistently underperformed
* Specific carriers had higher delay frequency

## Recommendations

* Optimize routes with repeated delays
* Improve capacity planning during peak times
* Re-evaluate underperforming carriers

## Tools Used

Python, SQL, Tableau
